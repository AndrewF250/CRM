# Changelog — CRM WebAgency

Формат: Keep a Changelog. Версия в файле `VERSION`.

## [1.2.3] — 2026-08-03

### Changed
- Базовая раскладка дашборда для всех (stats/docs/tasks/projects/goals/finances/calendar/reminders)
- Новый ключ localStorage — один раз подтянуть базовый layout; узкие экраны масштабируются через fitBoardScale

## [1.2.2] — 2026-08-03

### Added
- Интеграции: липкие вкладки GitHub / Сервер / AI, домен crm-seo-123.xyz
- AI-вкладки как в браузере: переименование, `+` новая нейронка
- Финансы: история (расходы+зарплаты+доходы из проектов), пресеты дат, настройки категорий
- Тёмный скроллбар

### Changed
- Финансы: кнопка `+`, фильтры типов, диапазон дат вместо месяца
- Настройки: кликабельная статистика аккаунта
- Обновить на интеграциях → иконка + время последнего обновления

## [1.2.1] — 2026-08-03

### Fixed
- Приоритет задач на дашборде как на вкладке «Задачи»
- Версия `0.0.0` на проде (VERSION рядом с server.js + fallback package.json)
- Превью вложений в карточках — тип файла, не полный embed
- Смена темы без перезагрузки страницы

### Added
- `+` в блоке связанных задач (создать и сразу связать)
- Прогресс целей по сроку (от start→end, двигается со временем)
- Масштабирование раскладки дашборда под ширину экрана
- Тултипы на приоритете и ключевых контролах

## [1.2.0] — 2026-08-03

### Added
- Версионирование продукта (`VERSION`, `CHANGELOG.md`, API `/api/app-info`)
- Настройки уведомлений: отдельно «за 7 дней» и «за 1 день» до дедлайна (задачи и проекты)
- Vault секретов + интеграции GitHub / SSH-деплой (бэкап БД, откат, keep-old)
- Интеграции нейронок: учёт токенов, дата покупки и обновления тарифа
- Тултипы на блоках интеграций и шагах деплоя
- Автоподключение SSH (чекбокс)

### Changed
- Профиль / логин / пароль пишутся в БД (bcrypt)
- Subtasks унифицированы в `tasks.parent_id`
- Документы проекта идут в `wiki_pages`
- Иконки: настройки в меню профиля, интеграции (шестерёнка + стрелки)
- Тёмная тема: контраст, select/dropdown

### Fixed
- Чекбоксы уведомлений реально влияют на серверные пуши
- Статус «не настроено» на интеграциях пояснён тултипами
